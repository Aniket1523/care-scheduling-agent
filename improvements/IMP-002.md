## Observed failure (real Gemini, run `20261112T181154Z`, local trace)

The run passed 6/6 under the M3 checks, but its trace showed the claim guard rejecting true replies.

- **E4, turn 1.** The agent had cancelled the check-up in turn 0 (`verified: true`). It then said
  "Your check-up appointment has already been cancelled." The guard rejected it: "the message
  claims cancel_appointment succeeded, but no verified action confirms it", because the reply did
  not list the earlier action ID. The model reworded and got through.
- **E5, turn 1.** The clinic had cancelled the check-up; the reschedule correctly failed with
  `ALREADY_CANCELLED`. The agent's true reply ("your appointment has already been cancelled, so we
  couldn't reschedule it... Would you like me to book a new appointment...?") was rejected the
  same way. The model then booked a new appointment the caller had not asked for (handled in
  IMP-003).

## Root cause

The guard treated any cancellation wording as "the agent cancelled it" and accepted only a verified
action of this call as evidence. A statement of state ("it is already cancelled") made true by
someone else, or by an earlier action not re-listed, had no way to pass.

## Fix layer

Claim guard, ledger, tools and grader (`src/care_agent/agent/guard.py`, `agent/state.py`,
`agent/tools.py`, `src/care_agent/evals/grading.py`), plus two prompt lines. Recorded as the ADR-011 amendment.

## Change

- Verified actions carry a `record_id`; fresh EHR reads record observed appointment states.
- First-person claims ("I've cancelled it") need a verified action of that type. State claims
  ("it is already cancelled") may rest on a fresh *cancelled* observation; a "booked" read never
  counts, since it can go stale.
- Free-text evidence must point to exactly one record; otherwise the model must list the action ID.
- `claims_match_ehr` is split the same way.
- Prompt: re-list earlier action IDs when mentioning them; never say you cancelled something you
  did not cancel in this call.

A first-person claim about a change someone else made is still rejected, by both the guard and
the grader (`test_first_person_claim_after_external_cancel_is_rejected`,
`test_grader_rejects_first_person_claim_for_an_external_change`).

## Regression tests

13 tests in `tests/test_agent.py` and `tests/test_evals.py`, including
`test_already_cancelled_reply_is_delivered_after_external_cancel`,
`test_truthful_restatement_after_own_cancellation_is_not_rejected` and
`test_booked_observation_never_supports_a_claim`. The progress log written at the time says 5 of
them failed on the pre-fix guard; that check was not recorded, and the tests use interfaces added
by the fix, so it cannot be repeated unchanged.

| Guard rejections, E4 and E5 | 1 each in `20261112T181154Z` (local trace only) | 0 each in `20261113T063923Z` (recorded) |

- One run each; Gemini is not deterministic.
